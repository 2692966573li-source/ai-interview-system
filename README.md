# AI 模拟面试系统

这是一个面向求职练习的本地 AI 模拟面试项目。当前版本已经完成文字面试闭环和本地账号隔离：注册/登录后配置岗位、解析简历、开始问答、根据回答继续追问、每五轮整理一次记忆、结束面试、生成带回答证据的评估报告。

## 四个业务区域

项目界面严格分成四个区域，使用顺序也是 1 → 2 → 3 → 4。

### 01 面试准备区

你在这里填写目标岗位、难度、题目数量和重点技能，也可以上传 PDF、DOCX、TXT 或 MD 简历。

白话理解：这是给面试官看的“考前资料”。资料越具体，后续问题越贴近你的项目经历。

### 02 智能面试区

主 AI 面试官阅读你的最新回答，从其中挑一个具体技术、数字、经历或模糊点继续追问。系统还会从基础题库中检索相关题目，给主 AI 提供参考，但不会机械照读固定题目。

每完成五轮回答，副 AI“记忆管家”会把重要事实、关键词和待追问点整理成结构化摘要。原始对话仍保存在数据库中，不会真的被删除。

回答框还提供可选的浏览器语音输入：点击“语音输入”后，普通话识别结果会回填到文字框，发送前仍可修改。每条 AI 问题都可以单独朗读，也可以打开“自动朗读”让新问题自动播放。语音能力使用浏览器内置 Web Speech API，不会把音频上传到本项目后端（浏览器厂商可能按自身策略处理语音）；如果浏览器不支持，文字问答仍可正常使用。首次使用时请在浏览器提示中允许麦克风权限。

白话理解：主 AI 负责提问，副 AI 像会议记录员，定期把长对话压缩成提纲，减少以后反复携带全部文字的成本。

### 03 评估成长区

面试结束后生成专业能力、逻辑结构、表达沟通三个维度的报告。每个分数都尽量关联到真实回答轮次，方便复盘。

白话理解：报告不能只说“你得了 80 分”，还要指出这个判断来自哪段回答。当前支持在页面下载 PDF 和 Excel 两种复盘文件。

### 04 记录交付区

查看历史面试、重新打开会话和报告，或删除不需要的记录。

白话理解：这是本地面试档案柜。目前数据保存在电脑上的 SQLite 数据库中；每个账号只能看到自己的简历、会话和报告。

登录后，浏览器会保存一枚短期 JWT（签名身份凭证），每次访问私有接口都带上它。密码只保存为不可逆的 PBKDF2 哈希，后端不会保存明文密码。

## 项目组成

- frontend：Vue 3 前端，也就是浏览器里看到和操作的页面。
- backend：FastAPI 后端，负责接收请求、校验数据和组织业务流程。
- backend/app/ai：AI 能力层，包含主面试官、记忆管家、结束控制、题库检索和报告生成。
- data：运行数据区，保存 SQLite 数据库、ChromaDB 向量索引、上传文件和以后导出的报告；它已被 Git 忽略。

## 技术名词白话解释

- Vue 3：制作网页界面的工具，负责输入框、按钮、对话气泡和报告卡片。
- FastAPI：用 Python 写后端接口的工具，可以把“创建会话”“发送回答”等能力变成网页可调用的地址。
- API：前端和后端约定的传话窗口。按钮点击后，前端通过 API 把数据交给后端。
- LangChain：组织大模型调用的工具。本项目用它拼装系统要求、历史对话和用户回答，再交给百炼模型。
- 阿里云百炼：提供 qwen-plus 对话模型和 text-embedding-v4 向量模型的云服务。
- SQLite：一个单文件数据库，适合本地 MVP，负责保存会话、消息、摘要和报告。
- ChromaDB：向量数据库，负责按“语义相似”查题，不只比较字面是否完全相同。
- 向量化：把一段文字变成一串数字；意思相近的文字，数字位置通常也更接近。
- RAG：先从资料库找相关内容，再把结果交给大模型。本项目用它给面试官提供题库候选。
- Token：模型读取和生成文字时使用的计量单位。记忆摘要能减少后续重复传输的旧内容，但当前实现仍保留最近对话来保证追问连贯。
- 降级：云模型临时不可用时，系统改用本地规则继续给出基础追问和报告，保证页面不直接瘫痪。
- JWT：登录后发给浏览器的一段签名凭证，像“临时门票”；后端用它识别用户，过期后需要重新登录。
- PBKDF2 哈希：把密码和随机盐重复计算成一串摘要；即使数据库被看到，也不能直接还原密码。

## 本机启动

最简单的方法：在项目根目录右键运行 启动项目.ps1。它会分别启动后端和前端，并打开浏览器页面。

如果 PowerShell 阻止脚本运行，可以在本项目根目录执行：

    powershell -ExecutionPolicy Bypass -File .\启动项目.ps1

手动启动后端：

    cd backend
    .\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000

手动启动前端：

    cd frontend
    npm run dev -- --host 127.0.0.1

页面地址：http://127.0.0.1:5173

后端接口文档：http://127.0.0.1:8000/docs

## API Key 安全

百炼密钥只允许放在 backend/.env 的 DASHSCOPE_API_KEY 中。该文件已被 .gitignore 忽略。不要把密钥写入前端、源代码、截图、报告或 Git 仓库。

backend/.env.example 只提供字段示例，不包含真实密钥。
